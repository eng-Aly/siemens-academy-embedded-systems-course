# Siemens Academy Embedded Systems Course

This repository contains lecture materials and coursework from the Siemens Academy Embedded Systems curriculum, covering the following core modules:

* **Embedded Systems Architecture**
  * Introduction to Embedded Systems
  * Computer Architecture
  * ARM Microcontroller Architecture
  * Embedded C
* **AUTOSAR Platform**
* **Automotive Cybersecurity**
* **Automotive Communication**
* **Real-Time Operating Systems (RTOS)**
* **Agile Software Development**
* **Functional Safety**
* **Software Engineering for Embedded Systems**
* **AI for Embedded Software Engineers**
